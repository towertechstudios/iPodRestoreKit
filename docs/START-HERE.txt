iPod Restore Kit — 0.3.0 Public Beta 5
Tower Tech Studios · Nico Maentanis

REQUIREMENTS
Intel Mac: macOS Catalina 10.15.7 or newer.
Apple silicon Mac: macOS Big Sur 11 or newer.
The native Compatibility interface is used on older supported releases.
iPod touch is not supported. Feature availability varies by iPod and format.

INSTALL WITH THE PKG
1. Finish device operations, then quit the beta and the regular app.
2. Open the .pkg and follow macOS Installer's steps.
3. Open Applications > iPod Restore Kit Beta when installation finishes.

INSTALL WITH THE ZIP INSTEAD
1. Expand the ZIP on the Mac where you will use the app.
2. Drag iPod Restore Kit Beta.app into Applications.
3. Open it from Applications. Run one app edition at a time.

The app is ad-hoc signed. The installer is unsigned. Neither is Apple-notarized.
macOS may block its first launch. If you trust the download, use Apple's
per-app approval instructions after attempting to open it:
https://support.apple.com/en-us/102445
Current macOS: System Settings > Privacy & Security > Open Anyway.
On Catalina/older supported macOS, look in System Preferences > Security &
Privacy > General. Do not disable Gatekeeper. If macOS reports corruption or
malicious software, stop and report the exact message instead of bypassing it.

FIRST USE
Grant only the permissions needed for the features you choose. Finder controls
may require Accessibility and Automation; local media and Photos use their own
permissions. Device writes can require administrator approval.
Back up important iPod content before trying any operation that changes it.

The beta has a separate app identifier and preferences, but uses the existing
Documents/iRestore storage folder. It can see and modify the same backup and
firmware files as the regular build. Keep an independent copy of important
backups before testing. Removing the beta app does not remove this folder.

NETWORK IPODS
Use Send Companion to Mac to install the included companion 0.5.0/build 12.
Open iPod Bridge directly from Applications on the older Mac, leave sharing
open, then choose Connect to Open Companion on the main Mac. Start with
Check Compatibility. Read KNOWN-LIMITATIONS.md before a network restore.

App Updates checks GitHub releases for a signed update manifest.

APP UPDATES
Use the app menu > Check for App Updates, or Settings > Updates. Automatic
checks run at launch and once per day while enabled. Only published GitHub
releases with a valid pinned-key signature and matching installer are eligible.
Download progress is displayed; Open Installer rechecks the package before
launching the normal macOS Installer. Finish all device operations first.
Existing beta users with App Updates can upgrade in the app. No private release key
or GitHub token is bundled. The installer does not install a driver, launch
agent or helper service and does not grant Automation/Accessibility access.

FIRST-RUN APPEARANCE
New installations use Modern, with System Default colors and Standard surface.
Existing Modern/Classic preferences are retained. Choose Classic in Settings >
Appearance if you prefer it. Catalina through Ventura use Compatibility UI.

BETA 7 MEDIA SYNC
Select downloaded purchases from the Music/TV library and use Sync to iPod.
Eligible protected purchases continue through Apple sync preparation. In Finder,
select the iPod under Locations, choose the prepared music playlist or selected
Movies/TV titles, review any replacement prompt, then Apply/Sync. Apple handles
account/device authorization; preparation alone does not transfer protected files.
For Podcasts, use Sync > Podcasts > Allow Podcasts Access if macOS blocks the
library, then Refresh Podcasts. Only downloaded episodes are listed.

BETA 5: BACKUPS, MEDIA AND PLAYBACK
Dynamic Backup Settings changes a device's Local/iCloud destination by moving
and verifying its history, creating a new base, and cleaning up the source only
after integrity and (for iCloud) upload confirmation. Keep the same backups idle
on other Macs during a move. Cancel Move, Keep Both retains existing copies.
macOS can cache cloud data locally; reading/verifying/restoring downloads it.
Use iCloud Backups > Find Cloud Backups on another Mac with the same account.

Backup before media sync is on by default. Dynamic Backup reuses unchanged data;
without it, each sync creates a full local backup. Change this in Settings if
needed. Backup failure stops before media writes.

Media > YouTube can download and convert a single public/unlisted video. Turn
off automatic sync for Mac-only preparation. Downloads are TV Shows with the
channel as show name. Device sync still requires a supported writer/video model.
