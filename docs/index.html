Protected purchases

Use Apple’s authorized sync for eligible downloaded purchases. Being authorized on the Mac does not guarantee playback on the iPod. This app does not remove DRM.

Local or iCloud backups

Choose per iPod in Dynamic Backup Settings. Changing destination moves and verifies its history before source cleanup. Unchanged files are shared; keep Shared Backup Data with your snapshots. macOS can cache cloud files locally.

Network connection

The bridge is not a virtual USB port. Network firmware restore is experimental on listed older models. Network Dynamic Backups, media edits and cross-generation conversion remain unavailable.

Backup, artwork and restore requirements
  • Backups require readable mounted storage. Dynamic Backups need a confirmed serial and direct connection; network backup activation requires a complete matching-serial backup.
  • iCloud uploads are managed by macOS. Missing cloud data stops updates; no replacement full backup is started automatically. Automatic retention is local-only; cloud deletion is managed in Finder. Destination changes now use verified, resumable history moves with upload-gated cleanup. No extra encryption is added. Live account transfer still needs verification.
  • Direct media writers require a supported library layout. Compressed or SQLite libraries can block an otherwise supported model. Later nano and shuffle direct music writers are not implemented.
  • Photo/Color, Video and nano 1/2 use per-song artwork records fixed in Beta 4. Artwork repair copies no audio; on-device display still needs checking after safe eject.
  • “Disk mode” is the normal restore route, not a separate DFU loader. Recovery loaders need the matching Apple stage and physical validation. Green network and recovery labels describe implemented paths, not verified hardware results. Nano 2 DFU / NOR recovery is not implemented.
  • Mac means HFS+; Windows means FAT/FAT32 where allowed by the device. Shuffle uses Windows format. APFS and exFAT are not iPod restore targets.
  • FireWire requires a functioning host driver and appropriate power/cables. Optional driver integration remains experimental.

Before you connect

Do backups, transfers and photo sync work on every model?

Backups need readable mounted storage and a stable device identity. Media writers and artwork/photo profiles are model-specific; a category appearing in the library is not a guarantee that every item can be synced. Cross-generation conversion applies only to implemented direct-connection workflows. Network backup activation requires a complete matching-serial backup; network Dynamic Backup, media edits and cross-generation conversion remain incomplete.

What happens with Rockbox or click-wheel games?

Rockbox workflows require a matching implemented target, compatible build and the model’s bootloader prerequisites. Network Rockbox writes are unavailable. Game detection, archiving and importing .ipg files do not grant Apple game authorization. The game storefront is hidden in this beta.

What is different about Nano 2 recovery?

Nano 2 has boot-ROM and NOR recovery modes. This beta has no verified DFU/NOR bootstrap for them. If the Apple bootloader still works, disk mode may allow a normal matching restore. An original device-specific NOR backup is not interchangeable with a dump from another iPod.

What should I know before testing the beta?

The app is ad-hoc signed and not Apple-notarized. Beta preferences are separate, but files under Documents/iRestore are shared with the regular app. Run one version at a time and keep independent backups. Byte readback is not proof of successful boot. If a restore stops after writing, inspect the iPod and retain its log before another attempt.
